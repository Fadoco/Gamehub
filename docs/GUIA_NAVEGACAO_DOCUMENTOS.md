## 🎓 PADRÕES IMPORTANTES

### Como adicionar um novo módulo JavaScript
```javascript
// Arquivo: java/meu-modulo.js
(function() {
  const PRIVATE_VAR = 'privado';
  
  window.MeuModulo = {
    publicMethod() {
      return PRIVATE_VAR;
    }
  };
})();
```

### Como adicionar uma nova variável CSS
```css
:root {
  --minha-cor: #123456;
  --meu-tempo: 0.3s;
}

.elemento {
  color: var(--minha-cor);
  transition: all var(--meu-tempo);
}
```

### Como chamar Firestore seguro
```javascript
// Usar transações:
await window.FirebaseTransactions.purchaseGameTransaction(uid, games, price);

// Nunca fazer direto:
// await db.collection('users').doc(uid).update({...}); // ❌ ERRADO
```
